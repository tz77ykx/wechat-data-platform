# 公众号助手 Chrome 扩展

这是公众号数据平台配套的 Manifest V3 浏览器扩展，用于同步微信后台凭证、批量下载文章详情，以及抓取待深入分析的对标文章正文。

扩展不包含构建步骤，不需要 npm，直接加载本目录即可。

## 前提条件

- Chrome 或其他支持 Manifest V3 的 Chromium 浏览器；
- 已启动公众号数据平台，地址为 `http://localhost:5001`；
- 浏览器与平台运行在同一台电脑上；
- 已登录微信公众平台，并且只操作自己有权访问的账号。

如果修改了平台端口，需要同步修改 `background.js` 和 `popup.js` 顶部的 `FLASK` 地址，并调整 `manifest.json` 中的 `host_permissions`。

## 安装

1. 启动平台：

   ```bash
   python app.py
   ```

2. 打开 <http://localhost:5001>，确认平台可访问。
3. 在 Chrome 地址栏打开 `chrome://extensions/`。
4. 打开右上角「开发者模式」。
5. 点击「加载已解压的扩展程序」。
6. 选择本目录 `chrome_extension/`，不要只选择其中的某个文件。
7. 在浏览器扩展菜单中将「公众号助手」固定到工具栏，方便使用。

Edge 等 Chromium 浏览器也可使用对应的扩展管理页面，以「加载解压缩的扩展」方式安装。

## 凭证同步

1. 在同一浏览器中登录 [微信公众平台](https://mp.weixin.qq.com/)。
2. 打开后台任意数据页面。扩展会从后台请求中识别 Token 和 Fingerprint，并读取该域名的 Cookies。
3. 点击浏览器工具栏中的「公众号助手」。
4. 查看三项状态：
   - 绿色：已检测到；
   - 黄色：凭证较旧，建议重新打开后台刷新；
   - 灰色：未检测到。
5. 点击「一键同步到本地工具」。
6. 弹窗显示「同步成功」后，即可使用批量下载。

Token 通常约两小时后过期。出现登录失败、凭证失效或状态变黄时，重新打开微信后台，再同步一次。

## 批量下载文章详情

### 选择文章范围

「文章发布日期」支持：

- 最近 7 天；
- 最近 30 天；
- 最近 90 天；
- 自定义开始和结束日期。

日期按北京时间计算，包含起止当天。这里筛选的是**文章发布日期**，不会裁剪单篇详情 XLS 中的阅读统计日期。

### 选择下载方式

- **只补未导入详情的文章**：检查本地主库，只下载尚无详情快照的文章，适合每天补新数据。
- **重新更新范围内的全部文章**：重新下载范围内所有文章，适合更新近期文章的后续阅读和关注数据。范围外历史数据不变。

### 开始下载

1. 保持本地 Flask 平台运行。
2. 确认凭证已同步。
3. 选择发布日期和下载方式。
4. 点击「开始批量下载」。
5. 扩展会先刷新所选范围的微信文章列表，再逐篇打开详情页、点击「下载数据明细」并关闭页面。
6. 弹窗会显示当前进度、成功数和失败数。任务在扩展后台运行，关闭弹窗不会中断任务。

登录失败或返回的文章范围与选择不一致时，任务会停止，不会沿用旧下载队列。

## 自动导入下载文件

平台默认每 20 秒扫描：

```text
~/Downloads/Chrome_Downloads/
```

请让浏览器把 XLS 下载到该目录，或者启动平台前设置实际下载目录：

```bash
export DOWNLOADS_DIR="$HOME/Downloads"
python app.py
```

文件会被复制到项目的 `uploads/` 并自动导入。若浏览器启用了「每次下载都询问保存位置」，需要每次选择受监控目录；也可以关闭该选项，或下载后在「数据管理」页手动上传。

只补缺失详情以本地主库的真实快照为准，不只是根据文件是否存在判断。

## 抓取对标文章正文

「批量抓取正文」用于获取平台中**已有分析记录、但尚未保存正文**的对标文章，以便进一步分析。

使用前：

1. 在平台「对标分析」页导入文章 CSV；
2. 对需要深入分析的文章执行 AI 分析；
3. 回到扩展，点击「批量抓取正文」。

请控制频率并遵守平台规则。文章版权归原作者所有，抓取功能不授予复制、转载或重新发布原文的权利。

## 更新扩展

1. 等待正在运行的下载或抓取任务结束。
2. 获取项目新代码。
3. 打开 `chrome://extensions/`。
4. 找到「公众号助手」，点击「重新加载」。
5. 如果平台代码也更新了，重启本地 Flask 服务。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `cookies` | 读取 `mp.weixin.qq.com` 的登录 Cookies，用于本地数据请求 |
| `webRequest` | 识别微信后台请求中的 Token 和 Fingerprint |
| `storage` | 保存凭证状态、下载选项和任务进度 |
| `tabs` | 逐篇打开和关闭文章详情页 |
| `downloads` | 配合详情文件下载 |
| `scripting` | 在详情页执行下载操作 |
| `host_permissions` | 仅访问微信公众平台与本地 `localhost:5001` |

扩展不会把微信凭证发送到第三方服务器。同步目标是本机 `localhost:5001`，凭证随后保存在本地 SQLite 数据库中。数据库和日志仍应妥善保管，不要公开分享。

## 常见问题

### Token 显示「未检测」

确认已登录微信公众平台，然后打开或刷新后台的数据分析页面。仅打开登录页通常不会产生需要的请求。

### 同步失败或提示连接错误

确认 `python app.py` 正在运行，并能打开 <http://localhost:5001>。如果修改过端口，检查扩展中的 `FLASK` 地址和权限配置。

### 下载中途提示登录失效

Token 可能已过期。停止当前任务，重新打开微信后台并同步凭证，然后再开始。已导入文件不需要重复导入。

### 文件下载了，但平台没有自动导入

检查浏览器实际保存目录是否与 `DOWNLOADS_DIR` 一致，以及文件名是否属于支持的格式。也可以直接进入「数据管理」页手动上传。

### 点击开始没有反应

重新加载扩展并重启平台，然后重新打开扩展弹窗。仍失败时，在扩展管理页查看「Service Worker」错误日志。

### 更换电脑后可以使用吗

可以，但浏览器和平台默认需要在同一台电脑上。还需要重新安装扩展、登录微信后台并同步凭证。公众号数据库不会随扩展自动迁移，需要单独备份和复制。
